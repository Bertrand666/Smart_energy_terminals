# 硬件资源分配

> 本文档记录 STM32F407ZGT6（正点原子探索者 V3）的外设资源分配情况，避免开发过程中引脚冲突。

---

## 芯片概览

| 项目 | 规格 |
|------|------|
| MCU | STM32F407ZGT6 |
| 内核 | ARM Cortex-M4F, 168MHz |
| Flash | 1024KB |
| SRAM | 192KB (128KB + 64KB CCM) |
| GPIO | 114 个 |
| 封装 | LQFP144 |

## 中断优先级分配

> 使用 4 位抢占优先级（NVIC_PRIORITYGROUP_4）

| 优先级 | 外设/中断 | 说明 |
|--------|-----------|------|
| 0 | - | 保留（最高优先级） |
| 1 | HardFault | 硬件错误 |
| 2 | SysTick | 系统节拍 |
| 3 | USART1 | 调试串口 |
| 4 | USART2 | ESP8266 通信 |
| 5 | DMA | 数据传输 |
| 6-15 | - | 应用层中断 |

## 内存布局

```
Flash (1024KB):
┌────────────────────────────────────┐ 0x08100000
│                                    │
│         Application                │
│         (剩余空间)                  │
│                                    │
├────────────────────────────────────┤
│         .data (初始值)              │
├────────────────────────────────────┤
│         .rodata (只读数据)          │
├────────────────────────────────────┤
│         .text (代码)               │
├────────────────────────────────────┤
│         .isr_vector (向量表)        │
└────────────────────────────────────┘ 0x08000000

RAM (128KB):
┌────────────────────────────────────┐ 0x20020000
│         Stack (栈顶)               │
│            ↓                       │
│                                    │
│            ↑                       │
│         Heap                       │
├────────────────────────────────────┤
│         .bss (未初始化)             │
├────────────────────────────────────┤
│         .data (已初始化)            │
└────────────────────────────────────┘ 0x20000000

CCM RAM (64KB):
└────────────────────────────────────┘ 0x10000000 - 0x10010000
    可用于 FreeRTOS 任务栈或高速缓冲
```
