## 升级架构（规划）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   云服务器   │────▶│   ESP8266   │────▶│  STM32F407  │
│  (固件存储)  │     │  (下载代理)  │     │ (Bootloader) │
└─────────────┘     └─────────────┘     └─────────────┘
```

---

## Flash 分区（规划）

| 分区 | 起始地址 | 大小 | 说明 |
|------|----------|------|------|
| Bootloader | 0x08000000 | 32KB | 启动加载器 |
| App A | 0x08008000 | 480KB | 主应用分区 |
| App B | 0x08080000 | 480KB | 备份/升级分区 |
| Config | 0x080F8000 | 32KB | 配置参数区 |

---

## 升级流程（规划）

1. 设备订阅 OTA 主题，接收升级指令
2. 下载固件包到备份分区（支持断点续传）
3. 校验固件（CRC32 / 签名）
4. 设置升级标志，重启进入 Bootloader
5. Bootloader 验证并切换分区
6. 启动新固件，上报升级结果
7. 失败自动回滚到旧版本
