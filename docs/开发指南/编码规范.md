## 命名规范

### 文件命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 源文件 | 小写 + 下划线 | `gpio_driver.c` |
| 头文件 | 小写 + 下划线 | `gpio_driver.h` |
| 文档 | 中文或英文，保持一致 | `调试指南.md` 或 `debug-guide.md` |

### 变量/函数命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 局部变量 | 小写 + 下划线 | `buffer_size` |
| 全局变量 | g_ 前缀 | `g_system_tick` |
| 函数 | 模块前缀 + 动词 | `uart_send_data()` |
| 宏定义 | 全大写 + 下划线 | `MAX_BUFFER_SIZE` |
| 类型定义 | 驼峰 + _t 后缀 | `UartConfig_t` |
