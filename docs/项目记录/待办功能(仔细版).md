# 待办功能清单 (Task List)

## 第一阶段：集成 FreeRTOS 前 (基础巩固)
> **目标**：清理冗余代码，建立稳固的硬件驱动层，确保系统在裸机状态下稳定运行。

### 1. CubeMX 生成代码清理 (高优先级)
- [ ] **HAL 模块裁剪**：`stm32f4xx_hal_conf.h` 中注释掉未使用的模块 (ETH, CAN, CRYP 等)，仅保留 GPIO, UART, TIM, DMA, RCC, FLASH, PWR, CORTEX。
- [ ] **中断处理清理**：`stm32f4xx_it.c` 中删除空壳中断处理函数 (NMI, SVC 等)，启动文件中已有 `[WEAK]` 默认实现。
- [ ] **系统文件瘦身**：`system_stm32f4xx.c` 中清理未使用的外部存储器初始化代码 (SystemInit_ExtMemCtl)。

### 2. 错误处理机制优化 (高优先级)
- [x] **UART 错误处理**：`uart.c` 中 `MX_USART1_UART_Init()` 初始化失败时，由死循环改为 `NVIC_SystemReset()` 自动复位和错误日志记录。
- [x] **Main 错误处理**：`main.c` 中 `Error_Handler()` 改为系统复位和错误日志记录。
- [x] **Fault 处理**：改进 `stm32f4xx_it.c` 中的 HardFault/BusFault 等，将 `while(1)` 替换为错误日志记录和自动复位。

### 3. 基础外设驱动开发 (高优先级)
- [x] **USART** (已完成)：实现基础收发与 printf 重定向。
- [x] **TIM** (已完成)：替代 HAL_Delay 实现非阻塞延时，验证中断回调。
- [ ] **SPI** (待实现)：
  - 目标：驱动 W25Q128 (Flash) 或 LCD 屏幕
  - 验证：读写 Flash ID 或点亮屏幕
  - 模式：先实现轮询/中断模式
- [ ] **I2C** (待实现)：
  - 目标：驱动 EEPROM (AT24C02) 或 温湿度传感器 (AHT20)
  - 验证：实现设备地址扫描与寄存器读写
  - 建议：优先使用软件 I2C (稳定性好)

### 4. 代码规范与基础建设 (中优先级)
- [ ] 添加 `.clang-format` 文件统一代码风格。
- [ ] 在 `CMakeLists.txt` 中添加版本信息 (PROJECT_VERSION_MAJOR/MINOR)。
- [ ] 统一文档命名风格 (中文/英文) 及源文件命名规范 (小写+下划线)。
- [ ] 添加统一的错误码定义 (error_code.h)。

## 第二阶段：集成 FreeRTOS 后 (系统升级)
> **目标**：引入实时操作系统，实现任务调度、多线程安全及高级功能。

### 1. FreeRTOS 集成与适配
- [ ] 使用 FreeRTOS 的 CMake 原生支持。
- [ ] 配置 `FreeRTOSConfig.h` (注意 F407 堆大小 192KB)。
- [ ] 重定义 `HAL_Delay` (弱定义)，实现与 FreeRTOS 共用 SysTick 定时器。
- [ ] 实现 `_sbrk()` (带 heap/stack 撞线检查)，封装 `app_malloc/app_free`。

### 2. 驱动升级与并发安全
- [ ] **USART 升级**：添加 DMA 接收支持 (FreeRTOS 建议方式)，引进错误计数器，防止无限重启。
- [ ] **SPI 升级**：RTOS 阶段升级为 DMA 模式。
- [ ] **线程安全**：实现线程安全的 `printf` (使用互斥锁)。
- [ ] **调试增强**：HardFault 输出寄存器值，便于定位 RTOS 任务堆栈溢出。

### 3. 高级功能与安全
- [ ] **网络通信**：若涉及 MQTT，使用 TLS 加密。
- [ ] **配置管理**：敏感配置 (WiFi, 密钥) 不要硬编码，使用外部配置文件或加密存储。
- [ ] **构建增强**：考虑添加静态分析工具 (cppcheck) 到 CI 流程，添加 Debug/Release 构建分离。
