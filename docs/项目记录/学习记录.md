## 一、STM32 定时器中断配置（TIM）

> 以本项目 TIM3 定时 1s 翻转 LED 为例

### 1. 核心公式

```
中断周期 = (PSC + 1) × (ARR + 1) / TIM_CLK
```

- **PSC（Prescaler）：** 预分频器，将定时器输入时钟分频
- **ARR（Auto Reload Register）：** 自动重装载值，计数器从 0 数到 ARR 后溢出触发中断
- **TIM_CLK：** 定时器的输入时钟频率

本项目计算过程：
```
TIM3 挂在 APB1 总线，时钟 = 84MHz

目标：1s 触发一次中断

PSC = 8399   →  84MHz / (8399+1) = 10kHz，即每个计数耗时 0.1ms
ARR = 9999   →  (9999+1) × 0.1ms = 1000ms = 1s
```

### 2. 涉及的四个文件及职责

配置一个定时器中断需要修改四个文件，各有明确分工：

```
timer.c           ── 定时器参数配置 + 中断回调（业务逻辑）
stm32f4xx_hal_msp.c  ── 硬件层准备（时钟使能 + NVIC 中断使能）
stm32f4xx_it.c       ── 中断入口函数（固定模板）
main.c               ── 调用初始化函数启动定时器
```

#### 文件 1：timer.c — 填参数 + 写回调

```c
#include "timer.h"

TIM_HandleTypeDef htim3;

// 配置定时器参数
void MY_TIM3_Init(void)
{
  htim3.Instance = TIM3;
  htim3.Init.Prescaler = 8399;            // 84MHz / 8400 = 10kHz
  htim3.Init.CounterMode = TIM_COUNTERMODE_UP;
  htim3.Init.Period = 9999;               // 10000 × 0.1ms = 1s
  htim3.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
  htim3.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_ENABLE;
  HAL_TIM_Base_Init(&htim3);              // 内部自动回调 HAL_TIM_Base_MspInit()
  HAL_TIM_Base_Start_IT(&htim3);          // 启动定时器中断
}

// 定时器溢出时执行的回调（覆盖 HAL 库的 __weak 版本）
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim->Instance == TIM3) {
    HAL_GPIO_TogglePin(GPIOF, GPIO_PIN_9);  // 翻转 LED
  }
}
```

**要点：**
- `HAL_TIM_Base_Init()` 内部会自动回调 `HAL_TIM_Base_MspInit()`，不需要手动调用
- `HAL_TIM_Base_Start_IT()` 启动计数器并使能更新中断
- `HAL_TIM_PeriodElapsedCallback()` 是 HAL 库中 `__weak` 定义的回调，这里写强定义来覆盖

#### 文件 2：stm32f4xx_hal_msp.c — 硬件层准备

```c
void HAL_TIM_Base_MspInit(TIM_HandleTypeDef *htim)
{
  if (htim->Instance == TIM3)
  {
    __HAL_RCC_TIM3_CLK_ENABLE();              // 使能 TIM3 时钟
    HAL_NVIC_SetPriority(TIM3_IRQn, 3, 0);   // 设置中断优先级
    HAL_NVIC_EnableIRQ(TIM3_IRQn);            // 打开 NVIC 中断开关
  }
}
```

**要点：**
- 此函数由 `HAL_TIM_Base_Init()` 自动调用，不需要在 main 中手动调用
- 职责是"给硬件通电"：时钟使能 + 中断使能
- 和 UART 的 `HAL_UART_MspInit()` 是同一套机制

#### 文件 3：stm32f4xx_it.c — 中断入口

```c
extern TIM_HandleTypeDef htim3;

void TIM3_IRQHandler(void)
{
  HAL_TIM_IRQHandler(&htim3);    // HAL 库清除中断标志 → 自动调用 Callback
}
```

**要点：**
- 函数名 `TIM3_IRQHandler` 必须与启动文件 `startup_stm32f407xx.s` 中的向量表一致
- `extern` 引用 timer.c 中定义的 `htim3` 句柄
- 函数内部只需调用 `HAL_TIM_IRQHandler()`，它会清除标志并回调你的 Callback

#### 文件 4：main.c — 启动

```c
#include "timer.h"

int main(void)
{
  HAL_Init();
  SystemClock_Config();
  MY_GPIO_Init();
  MY_USART1_UART_Init();
  retarget_stdio_init();
  MY_TIM3_Init();               // 启动定时器，之后 LED 自动闪

  while (1)
  {
    // 主循环空闲，LED 由定时器中断自动翻转
  }
}
```

### 3. 完整调用链

```
MY_TIM3_Init()                                          ← 你调用
  ├→ HAL_TIM_Base_Init(&htim3)                          ← HAL 库
  │    └→ HAL_TIM_Base_MspInit(&htim3)                  ← HAL 自动回调你的实现
  │         ├→ __HAL_RCC_TIM3_CLK_ENABLE()              ← 使能时钟
  │         ├→ HAL_NVIC_SetPriority(TIM3_IRQn, 3, 0)   ← 设置优先级
  │         └→ HAL_NVIC_EnableIRQ(TIM3_IRQn)            ← 打开中断
  └→ HAL_TIM_Base_Start_IT(&htim3)                      ← 启动计数 + 使能中断

       ... 计数器从 0 数到 9999，耗时 1s ...

  TIM3_IRQHandler()                                     ← CPU 硬件自动跳转
    └→ HAL_TIM_IRQHandler(&htim3)                       ← HAL 清除中断标志
         └→ HAL_TIM_PeriodElapsedCallback(&htim3)       ← 你的回调
              └→ HAL_GPIO_TogglePin(GPIOF, GPIO_PIN_9)  ← 翻转 LED
```

### 4. CMakeLists.txt 需要添加的内容

```cmake
# 源文件
${PROJ_ROOT}/drivers/timer/timer.c
${HAL_DIR}/Src/stm32f4xx_hal_tim.c
${HAL_DIR}/Src/stm32f4xx_hal_tim_ex.c

# 头文件路径
${PROJ_ROOT}/drivers/timer
```

同时确保 `stm32f4xx_hal_conf.h` 中 `HAL_TIM_MODULE_ENABLED` 已启用。

### 5. 配置新定时器的通用模板

如果以后要再加一个定时器（比如 TIM4 定时 500ms），只需要：

1. **timer.c** — 新增 `htim4` 句柄 + `MY_TIM4_Init()` + 在 Callback 中加 `if (htim->Instance == TIM4)` 分支
2. **stm32f4xx_hal_msp.c** — 在 `HAL_TIM_Base_MspInit()` 中加 `if (htim->Instance == TIM4)` 分支
3. **stm32f4xx_it.c** — 新增 `TIM4_IRQHandler()`
4. **main.c** — 调用 `MY_TIM4_Init()`

结构完全一致，换个名字和参数就行。
