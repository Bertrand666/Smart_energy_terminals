- 配置链接脚本（.ld）、启动文件（startup_stm32f407xx.s）

### 4. 调试环境配置

## 二、外设驱动实现

### 1. GPIO 驱动
- 实现 `MY_GPIO_Init()`，配置 PF9 为推挽输出（LED 控制）
- 实现 LED 1s 间隔闪烁（裸机验证）
- 清理冗余时钟使能（移除未使用的 GPIOA/GPIOH 时钟）
- 调整初始化顺序（先配置引脚模式，再设置电平）

### 2. UART 串口驱动
- 实现 `MY_USART1_UART_Init()`，配置 USART1 @ 115200bps
- 在 `stm32f4xx_hal_msp.c` 中实现 `HAL_UART_MspInit()` 完成 GPIO 复用配置
- 实现 printf 串口重定向（`retarget.c`），支持 `printf()` 直接输出到串口
